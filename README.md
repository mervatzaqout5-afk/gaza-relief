## Important
This starter version uses a direct injected TRON wallet provider for the transaction flow. For production multi-wallet support, integrate the current official TronWallet Adapter packages and WalletConnect TRON adapter.

Do not put a seed phrase or private key anywhere in this project.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. In Settings → Pages, choose "Deploy from a branch", select `main` and `/root`.
4. Open the generated GitHub Pages URL.

## Test first
Use a TRON testnet before accepting real donations. Never test with a private key or seed phrase.
